# Mind Map 使用指南 %%w=504%%

这张图本身就是一篇普通的 Markdown 笔记，用脑图视图打开而已。切到 Markdown 就能看到它的源码，改哪边另一边都跟着变。

按 `/` 折叠展开一支，工具栏的层级按钮可以一键「展开全部」。

## 从这里开始 %%green fold%%

### 怎么新建

- 文件夹右键 → **新建思维导图**
- 命令面板 → **新建思维导图**
- 左侧边栏的脑图图标

### 怎么把已有笔记变成脑图

frontmatter 就是笔记最开头 `---` 包起来的那几行。

- 在 frontmatter 里加一行 `mindmap: true`，之后这篇笔记默认就以脑图打开
- 或者笔记右键 → **以思维导图打开**，只看一次不改文件

### 怎么切回 Markdown

- 脑图右上角的文档按钮，或命令 **在思维导图和 Markdown 之间切换**
- 文件右键 → **以 Markdown 打开**；切过去之后右上角有按钮切回脑图
- 两个视图共用一个文件，来回切不会丢东西
- 不想让切换写入 `mindmap: true`，在设置里关掉「切换成思维导图时记住」

### 边写边看

- 命令 **在右侧以思维导图预览**：左边照常写 Markdown，右边实时长出脑图
- 不改文件，适合只想用脑图看一眼大纲

### 三种打开方式

- 整篇笔记：一张大图，占满标签页
- 代码块嵌入：普通笔记里插一段 mindmap 代码块，渲染成小图
- 嵌入已有脑图：`![[脑图笔记]]`、`![[文件.xmind]]` 显示只读预览
- `.xmind` 文件：直接拖进 vault 就能打开

## 编辑节点 %%blue%%

### 增删改 %%fold%%

- Tab 加子节点，Enter 加兄弟节点，Shift+Enter 插到当前节点前面，⌘↵ 插入父节点
- 双击 / 空格 / F2 进入编辑，默认全选文字、打字直接替换；想接着写可以在设置「进入编辑节点时」改成光标在末尾。Enter 提交，Esc 取消
- Delete / Backspace 删除节点和它下面的整棵子树
- ⌘⌫ 只删这一个节点，它的子节点接到原来的位置（右键菜单「仅删除此节点」）
- 编辑时 Shift+Enter 换行，多行文本存成 `<br>`

### 挪位置 %%fold%%

- **拖拽节点**到另一个节点上，或者它后面的空白处，成为它的子节点；先多选几个再拖，整组一起走
- 拖到画布边缘，画布会自动跟着滚
- 拖到子节点之间的空隙里，插到那个位置
- 左右分布结构里，拖到另一侧也可以，拖到哪边就固定在哪边（`%%left%%` / `%%right%%`），别的分支不会被挤过去
- Alt+↑↓ 在兄弟之间排序，Alt+←→ 升级降级，多选时整组一起动

### 选中 %%fold%%

- 单击选中，Shift 点击加选，⌘ 点击反选
- Shift 在空白处拖动 = 框选
- 习惯 XMind：设置里「左键拖动空白处」选「框选」，左键直接框选，右键或中键拖动平移
- ⌘A 全选；多选后上色、删除对整组生效

### 浮动工具栏 %%fold%%

选中节点后，节点上方会浮出一条小工具栏。

- 九种颜色 + 清除颜色
- 加子节点 / 加兄弟节点
- 标记、备注、外框、链接笔记
- 复制子树 / 粘贴为子节点 / 删除

### 右键菜单 %%fold%%

- 节点上：编辑、增删、聚焦、折叠、链接、备注、标记、任务、转标题/列表、复制链接
- 空白处：粘贴、展开全部、只显示主主题、适应画布
- 工具栏上：切换工具栏位置

## 节点能做什么 %%purple%%

### 颜色 %%fold%%

颜色以 `%%green%%` 的形式存在行尾。这是 Obsidian 的注释语法，阅读模式里看不见。

- 🟥 红 %%red%%
- 🟧 橙 %%orange%%
- 🟨 黄 %%yellow%%
- 🟩 绿 %%green%%
- 🟦 蓝 %%blue%%
- 🟪 紫 %%purple%%
- 青 / 粉 / 灰 %%teal%%

### 标记 %%fold%%

标记就是存在文字开头的 emoji，任何地方都显示得出来，别的软件打开也不会乱。

- 1️⃣ 优先级 · 五个数字，同组互斥
- ⏳ 进度 · 待办、完成、放弃
- 🚩 旗帜 · 六种颜色
- ⭐ 符号 · 星、感叹、问号、灯泡、警告、火、心、图钉

### 备注 %%fold%%

这段话本身就是一条备注。备注里可以写代码：

```js
console.log("hello");
```

写回文件时它就老老实实待在节点下面。

- 节点下面的段落就是备注，节点上会出现一个 ≡ 图标
- 点 ≡ 查看，工具栏的备注按钮直接编辑
- 查看弹窗右下角可以拖动改大小，下次打开沿用；备注里的图片点一下全屏放大
- 编辑备注时直接粘贴或拖入图片，自动存进附件、插在光标处；编辑节点文字时粘贴图片，会加到这个节点的备注里
- 节点右键 → 更多 → 在 Markdown 中定位，直接跳到这一行；切回脑图会选中光标所在的节点
- 备注支持 Markdown：列表、代码块、加粗都行

### 自由主题 %%fold%%

不和中心主题连线、可以随便摆的主题，适合放灵感、待定的问题。

- 双击空白处，或者右键空白处 → 在这里新建自由主题
- 节点右键 → 更多 → 转为自由主题，连同分支原地脱离出来
- 拖动它就能挪位置；拖到某个节点上就挂过去，右键 → 更多 → 挂回中心主题也行
- 在自由主题上按 Enter，在它下方再建一个
- 设置里打开「把节点拖到空白处变成自由主题」，就能像 XMind 那样直接拖出来（默认关）
- 存成中心主题下带 `%%float x=320 y=-80%%` 的普通章节，Markdown 里照样能读

### 外框 %%fold%%

把一个节点连同它的分支框起来，或者把几个相邻的兄弟框成一组。

- 选中后点工具栏的外框按钮，或按 ⌘⇧B；⌘⇧B 再按一次去掉
- 先多选几个相邻的兄弟再加，就框成一个 %%box=2 "这两条是一组"%%
- 加标题：双击外框里的空白处直接写；右键外框里的空白处，或选中框内节点再点一次外框按钮，可以加 / 改标题、移除外框
- 改框住的范围：单击外框里的空白处选中它，拖上下两头的小手柄；右键也有「范围多括一个 / 少括一个节点」
- 存成 `%%box%%`、`%%box=2 "标题"%%`，导出图片时一起带上

### 概要 %%fold%%

几个相邻的兄弟外侧画一个大括号，后面挂一句概括。

- 选中一个或几个相邻的兄弟，右键 → 添加概要，加上就直接写文字 %%summary=2 "前两条是操作"%%
- 文字支持行内 Markdown，可以放 [[链接]]、**加粗**
- 双击概要文字修改，右键概要可以移除；清空文字也等于移除
- 拖概要外侧边缘的小竖条改宽度，文字跟着换行；双击竖条恢复自适应
- 改括住的范围：单击概要文字，大括号两头出现小手柄，拖到哪个兄弟就括到哪；右键也有「范围多括一个 / 少括一个节点」
- 括号会括住这几个节点连同它们的分支，左右分布时左边的朝左，组织结构图里画在下方
- 存成 `%%summary=2 "文字"%%`，导出图片时一起带上

### 节点宽度 %%fold%%

- 选中节点，拖它外侧边缘的小竖条改宽度，文字跟着换行；拖到画布边缘会自动跟着滚
- 双击竖条或右键 **恢复自动宽度** 还原
- 存成 `%%w=240%%`，中心主题「Mind Map 使用指南」就设了宽度

### 任务复选框 %%fold%%

- [ ] 还没做的事
- [x] 已经做完的事
- [ ] 点一下方框在「未完成 → 完成 → 去掉」之间切换

### 标签与公式

- 写 `#标签` 会渲染成标签样式，点击打开全局搜索 #脑图/示例
- 写 `$E = mc^2$` 渲染成公式：$E = mc^2$
- 两对 `$$` 按展示样式排，大一号：$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$
- 多行公式用 aligned 环境：$\begin{aligned} a &= b + c \\ d &= e \end{aligned}$
- 更长的公式写进备注里，用 `$$` 块，跟普通笔记一样
- 加粗 **像这样**，斜体 *像这样*，⌘B / ⌘I 对整个节点生效

### 图片 %%fold%%

- 拖一张图片进画布，或者直接 ⌘V 粘贴，会存进附件目录并生成图片节点
- 语法就是 Obsidian 自己的 `![[图片.png|160]]`，竖线后面是宽度
- 选中图片节点，右下角有个手柄，**拖动改大小**，双击手柄恢复原始尺寸
- **双击图片看大图**，点任意处或 Esc 关闭；双击节点的文字部分还是编辑
- 网图也能直接引：![Obsidian|120](https://obsidian.md/images/obsidian-logo-gradient.svg)

### 视频嵌入 %%fold%%

从 B 站、YouTube 那里复制的 `<iframe …>` 嵌入代码，直接粘进节点就渲染成播放器。

- <iframe width="278" height="157" src="https://player.bilibili.com/player.html?bvid=BV1WAuG6wEWZ&page=1&high_quality=1&danmaku=0" title="Bilibili video player" frameborder="0" allowfullscreen></iframe>
- 只认 iframe 这一个标签，`src` 必须是 http(s)；`javascript:` 和别的标签一律当普通文字显示
- 宽高取代码里的 width / height，钳在 80–1200 之间
- 播放器上盖了一层挡板：单击只是选中节点，激活之后才能播放、才点得到「进入 B 站」那种跳转按钮
- 两种激活方式：**双击画面**，或者点右下角浮出来的**「激活」按钮**（鼠标悬停时出现，节点选中时常驻）
- 激活的节点带一圈虚线；点画布空白处或选别的节点就自动收回挡板
- 选中后右下角有手柄，**拖动改大小**（默认锁 16:9，按住 Shift 单独拉高度），双击恢复 560×315
- 默认**不自动播放**，展开也只是把播放器摆在那儿，想看点一下
- 真要它自己播，在地址里写 `autoplay=1`
- 折叠着的分支根本不加载，展开才建 iframe
- 备注里也能放，那条路走 Obsidian 自己的渲染器，点开 ≡ 才加载

### 链接到笔记 %%fold%%

- 编辑时直接打 `[[`（中文输入法打 `【【` 也行），弹出文件列表，回车插入
- 先选中文字再打 `【`，包成【文字】；再打一次变成 `[[文字]]` 链接
- ⌘K 或工具栏的链接按钮，搜一篇已有笔记挂上去
- 搜不到就直接按这个名字新建一篇，并在右侧分栏打开
- 挂上之后标签变成 `[[笔记名|原来的文字]]`，按住 ⌘ 悬停有预览
- 从文件列表把笔记拖到节点上，也会变成一个链接子节点
- 就像这一个 → [[脑图代码块嵌入示例|一篇带嵌入脑图的笔记]]，按住 ⌘ 悬停能预览
- 外部网址写成 Markdown 链接就行，比如 [Obsidian 官网](https://obsidian.md)，点击用浏览器打开
- 直接粘一个裸网址也会自动成链，句尾的标点不会被吃进去
- 官网是 https://obsidian.md 可以点

### 复制节点链接 %%fold%%

- 标题节点给 `[[笔记#标题]]`
- 列表节点自动补一个块 id，给 `[[笔记#^id]]`
- 别的笔记里可以直接引用脑图里的某一个节点

## 看图与找东西 %%teal%%

### 缩放平移 %%fold%%

- 滚轮 / 拖空白处 = 平移
- ⌘+滚轮 / 双指捏合 / ⌘= ⌘- = 缩放
- 习惯 XMind 的话，设置里把「鼠标滚轮」改成缩放，Shift+滚轮平移
- ⌘0 适应画布，⌘⇧0 缩放到选中的分支，点工具栏的百分比回到 100%

### 折叠 %%fold%%

- 节点右边的小圆点，或者按 `/`
- 数字键 1–9：选中节点往下只显示 N 层，0 把这一支全部展开，其他分支不动；选中中心主题时作用于整张图并适应画布
- 工具栏层级按钮：展开全部、只显示主主题、显示到第 2 / 3 层
- 折叠状态存在文件里（`%%fold%%`），下次打开还是这样

### 聚焦分支 %%fold%%

- 右键 → **聚焦此分支**，把这一支当成根单独看
- 顶部出现面包屑，点一下回到全图或任意一层祖先
- Esc 也能退出

### 搜索 %%fold%%

- ⌘F 打开搜索框
- 匹配的节点高亮，Enter / Shift+Enter 在结果之间跳
- 折叠着的祖先会自动展开，跳到哪里就居中到哪里

### 大纲面板 %%fold%%

- 工具栏最左边的按钮，或命令**切换大纲面板**
- 左侧出现树形列表，和画布双向联动
- 在大纲里就能改名字、调层级

### 背诵模式 %%fold%%

把脑图当复习卡用：工具栏的眼睛按钮，或命令**切换背诵模式**。只改显示，不写进文件。

- 填空：节点里用 ==高亮== 标出要背的词，背诵模式下遮成横线，点一下揭开、再点盖回
- 选择题：题目的子节点写成 `[x] 正确选项`、`[ ] 错误选项`，背诵模式下全都显示成没勾，点题目揭晓：对的变绿、错的变淡
- 正确选项有两个以上的题目自动标「多选」

## 换个样子 %%orange%%

### 七个主题 %%fold%%

工具栏的调色盘按钮切换。切完会写进 frontmatter 的 `mindmap-theme`，这一篇就固定用它。

- 雪松 · 深色中心，灰底节点（默认）
- 彩虹 · 分支各一色，曲线
- 商务 · 蓝色系，直角折线
- 暖阳 · 橙调，大圆角曲线
- 极简 · 黑白描边，细线
- 线条 · 纯文字节点，细折线
- 森林 · 绿调分支，曲线

### 自定义主题 %%fold%%

设置 → 自定义主题 → 新建，选一个内置主题当起点，右边实时预览。

- 按 4 档层级改：中心主题 · 主主题 · 子主题 · 第 3 层及以下
- 每档可改字号、粗体斜体、文字色、背景或下划线、圆角、边框、最大宽度（可选同层宽度对齐）、连线颜色粗细
- 整体可改连线类型、拐角、虚线、分支各一色、间距
- 深色配色自动推算；保存后在调色盘菜单里选用

### 连线样式 %%fold%%

工具栏调色盘旁边的连线按钮，和主题配色分开选，写进 `mindmap-edge` / `mindmap-edge-dash` / `mindmap-edge-corner`。

- 跟随主题 · 曲线 · 直角折线 · 直线
- 虚线开关
- 圆角拐角开关：关掉就是尖角

### 四种结构 %%fold%%

工具栏的结构按钮切换，写进 `mindmap-structure`。

- 逻辑图（向右）· 全部往右铺开
- 思维导图（左右分布）· 中心在中间，左右各一半 ← 这张图用的就是它
- 组织结构图（向下）· 自上而下，像组织架构
- 树形图 · 缩进式，像文件树

### 工具栏位置 %%fold%%

- 上方 / 下方是水平条，左侧 / 右侧是垂直条
- 设置里改，或者直接在工具栏上右键

## Markdown 就是数据 %%gray%%

### 映射规则 %%fold%%

默认前三级用标题，再往下用列表，可以在设置里改。

- `# 一级标题` → 中心主题（没有就用文件名）
- `## ～ ###### 标题` → 各级节点
- `- 列表项`（缩进嵌套）→ 更深的层级
- 节点下面的段落 → 备注

### 藏在注释里的东西 %%fold%%

用的是 Obsidian 的 `%%注释%%` 语法，阅读模式和别的编辑器里都看不见，不会污染正文。

- 颜色：`%%green%%` 或 `%%#a3e5a2%%`
- 折叠：`%%fold%%`
- 节点宽度：`%%w=240%%`
- 左右分布里固定在哪边：`%%left%%` / `%%right%%`
- 外框：`%%box%%`、`%%box=3 "标题"%%`
- 概要：`%%summary%%`、`%%summary=3 "文字"%%`
- 自由主题：`%%float x=320 y=-80%%`（只认中心主题下的）
- 几个一起写就 `%%green fold w=240%%`

### 为什么这么设计 %%fold%%

- 脑图视图只是同一个 `.md` 的另一个编辑器，没有私有格式
- 插件哪天不用了，笔记还是好好的 Markdown
- 双链、标签、搜索、同步、版本管理全都照常
- XMind 导出的 Markdown 就是这套层级，可以直接打开；反过来也能被 XMind 导入

## 进出与嵌入 %%pink%%

### 导出 %%fold%%

- 导出为 PNG · 两倍分辨率，字体内嵌，和屏幕上一模一样
- 导出为 SVG · 矢量，放多大都清楚
- 复制为图片 · 直接粘到别的地方

### 打开 .xmind %%fold%%

- `.xmind` 文件放进 vault 就能直接打开，只读渲染
- 多个工作表可以切换
- 右上角一键**转换为 Markdown 笔记**，转完就能编辑
- XMind Zen / 2020 之后的 content.json 和 XMind 8 的 content.xml 都认
- 外框、概要和中心主题下的自由主题会一起转过来；联系线、概要下面挂的子主题、评论暂不支持，右上角会提示丢了几项

### 代码块嵌入

在任何普通笔记里写一个 mindmap 代码块，块里放同样的 Markdown，阅读模式和实时预览都会渲染成一张小图。

- 代码块名写成 gogoga-mindmap 也行；同时装了 Markmind 的话，可以在设置里关掉「渲染 ```mindmap 代码块」，把 mindmap 让给它
- 默认只读，点铅笔或双击节点进入编辑
- 改动直接写回这个代码块
- 撤销重做只作用在块里，不会波及整篇笔记
- 高度按内容自适应，上限在设置里调
- 活的例子：[[脑图代码块嵌入示例]]，里面插了两块，结构和主题各不一样

### 嵌入已有的脑图

想引用一张已经画好的脑图，像嵌入普通笔记一样写 `![[脑图笔记名]]`，XMind 文件写 `![[文件名.xmind]]`。

- 显示只读预览，原文件改了预览跟着变
- 点工具栏的「打开」或双击节点，打开原文件编辑
- 链接带上节点只显示那一支：`![[脑图#节点名]]`、重名写路径 `![[脑图#上级#节点名]]`，或块引用 `![[脑图#^id]]`
- 拖进白板（Canvas）也显示成脑图，铺满卡片
- 普通笔记照常显示

### 复制粘贴 %%fold%%

- ⌘C / ⌘X 复制、剪切整棵子树
- 剪贴板里是缩进列表形式的 Markdown，可以粘到任何地方
- ⌘V 把剪贴板里的内容粘成子节点，从别处抄来的列表也能直接变成分支

## 设置项

### 打开方式 %%fold%%

- 切换成思维导图时记住 · 关掉后切换只换当前标签页，不写 `mindmap: true`

### 新文件用什么 %%fold%%

- 默认结构 · 单篇可以用 `mindmap-structure` 覆盖
- 默认主题 · 单篇可以用 `mindmap-theme` 覆盖
- 标题的最深级别 · 比这更深就用列表写回
- 新文件的列表缩进 · Tab 或空格

### 界面 %%fold%%

- 文件列表里的图标 · 给脑图笔记配一个 icon，支持搜索选择
- 工具栏位置 · 上下左右
- 鼠标滚轮 · 平移（默认）或缩放
- 代码块嵌入的最大高度

### 悬停预览 %%fold%%

- 按住 ⌘ / Ctrl 停在链接节点上，弹出笔记预览
- 想不按键就显示，去核心插件「页面预览」的设置里找「思维导图」那一项

## 快捷键

### 增删改 %%fold%%

- Tab · 加子节点
- Enter · 加兄弟节点（在中心主题上是加子节点），Shift+Enter 插到前面
- 空格 / F2 / 双击 · 编辑
- Delete / Backspace · 删除
- ⌘⌫ · 仅删除此节点，保留子节点
- ⌘↵ · 插入父节点，选中的兄弟一起收进去
- ⌘B / ⌘I · 加粗 / 斜体
- ⌘⇧B · 加外框 / 去掉外框

### 选择与移动 %%fold%%

- 方向键 · 在节点之间走
- Shift+点击 / ⌘+点击 / Shift+拖拽 / ⌘A · 加选 / 反选 / 框选 / 全选
- Alt+↑↓ · 兄弟间排序
- Alt+←→ · 升级 / 降级

### 视图 %%fold%%

- `/` · 折叠、展开
- 1–9 / 0 · 选中节点往下只显示 N 层 / 这一支全部展开（右键菜单「折叠 / 展开」里也有「只展开下一级」「展开全部子分支」）
- ⌘F · 搜索
- ⌘= / ⌘- / ⌘0 · 放大 / 缩小 / 适应画布
- ⌘⇧0 · 缩放到选中的分支
- Esc · 取消选择，再按退出聚焦

### 其他

- ⌘C / ⌘X / ⌘V · 复制 / 剪切 / 粘贴子树
- ⌘K · 链接到笔记
- ⌘Z / ⌘⇧Z · 撤销 / 重做
- 加子节点、加兄弟、在前面插入、删除、仅删除此节点、上移下移、升降级、折叠、层级、外框、概要都是命令，可以在「设置 → 快捷键」里搜 gogoga Mind Map 绑成自己的习惯
