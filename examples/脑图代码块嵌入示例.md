# 脑图代码块嵌入示例

这是一篇**普通笔记**，frontmatter 里没有 `mindmap: true`。它照常是文字，只是中间插了几段 `mindmap` 代码块，阅读模式和实时预览都会把它们渲染成小脑图。

写作的时候用文字，需要理清结构的地方就插一张图，不用为了一张小图单独开一个文件。

## 插一张进来

围栏语言写 `mindmap`，块里的内容和整篇脑图笔记是同一套 Markdown 映射：

```mindmap
# 本周计划

## 产品
%%blue%%

- 1️⃣ 需求评审
- 2️⃣ 原型走查

## 研发
%%green%%

- ⏳ 接口联调
- ✅ 埋点上线

## 风险
%%red%%

- ❗ 设计稿还没定
```

颜色、标记、折叠这些在块里一样管用，因为它们本来就只是文本。

## 每一块可以不一样

块里可以再写一层 frontmatter，只对这一块生效：

```mindmap
---
mindmap-structure: org-down
mindmap-theme: business
---

# 发布流程

## 提测

## 回归

## 灰度

## 全量
```

同一篇笔记里，上面那块是默认的逻辑图 + 雪松主题，这块是组织结构图 + 商务主题。

## 怎么玩

- 默认**只读**，免得看笔记的时候手滑改了东西
- 点工具栏最左边的铅笔，或者双击任意节点，就进入编辑
- 改完立刻写回这个代码块，切走再回来还是你改的样子
- ⌘Z 撤销只作用在块里，不会把整篇笔记一起回滚
- 高度按内容自适应，超过设置里的上限就出滚动条
- 工具栏、右键菜单、拖拽、折叠，和整页脑图完全一样

## 什么时候用哪种

| | 整篇脑图笔记 | 代码块嵌入 |
|---|---|---|
| 加什么 | frontmatter 里 `mindmap: true` | 一段 `mindmap` 围栏 |
| 一篇几张 | 一张 | 想插几张插几张 |
| 适合 | 图就是这篇笔记本身 | 文章里顺手画一张说明结构 |
| 默认可编辑 | 是 | 否，点铅笔才编辑 |
