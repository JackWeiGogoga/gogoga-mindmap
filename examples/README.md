# 示例 / Examples

把这个文件夹整个复制进 vault 就能直接看。Copy the whole folder into your vault.

| 文件 | 内容 |
|---|---|
| `Mind Map 使用指南.md` | 用脑图打开的功能地图：每个功能都在上面，并且用插件自己演示（外框、节点宽度、公式、视频、链接……） |
| `脑图代码块嵌入示例.md` | 普通笔记里插 `mindmap` 代码块，两块用不同的结构和主题 |
| `产品发布计划.md` | 一张常规的左右分布脑图，带颜色、外框和左右固定 |
| `周会纪要.md` | 会议纪要里顺手插一张小脑图 |
| `竞品分析.xmind` | XMind 文件，在 Obsidian 里打开后可以一键转换成 Markdown 脑图 |

The notes are written in Chinese; the Markdown structure is what matters, and the main README explains it in English.
