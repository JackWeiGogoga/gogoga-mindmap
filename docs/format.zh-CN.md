# gogoga Mind Map 文件格式

[English](format.md) | **简体中文**

gogoga Mind Map 在 Obsidian 插件市场的下载已经超过一万次。很多人把读书笔记、课程、工作计划放在里面，最常被问的一句是：**哪天不用这个插件了，我的脑图还在吗？**

在。这个插件没有自己的文件格式，脑图就是一篇普通的 Markdown 笔记：标题和列表是节点，颜色、折叠这类样式写在 Obsidian 的注释 `%%…%%` 里。卸了插件，笔记照样能读、能改；用别的 Markdown 编辑器打开，看到的也是一份结构清楚的大纲。

这一页把规则写全：哪些行会变成节点，每个注释标记是什么意思，插件改文件时会动哪些东西，又有哪些东西不在笔记里。手写、用脚本生成、让 AI 来写，照这一页写就能被插件正确读出来。

## 兼容承诺

从 1.0.0 起，1.x 的每个版本都保证：

- **已有的写法意思不变。** 这一页列出的 frontmatter 键、标记、节点规则，以后的版本按同样的意思读。新功能只会加新的键或标记，不改旧的。
- **旧写法一直能读。** 早期版本写下的格式（比如标题行末尾的标记、带 `#` 的色值）照样认，只有在脑图里改到那个节点时，才换成现在的写法。
- **不认识的不碰。** 一个 `%%…%%` 里只要有一个词插件不认识，整段就当普通注释，原样留着；frontmatter 里别的插件的键、正文里插件不管的内容，也都原样保留。
- **不需要迁移。** 升级插件不会批量改写你的笔记。

如果哪天真要改变某个写法的意思，会放到 2.0，并在更新日志里提前写明。

## 脑图放在哪

| 写法 | 怎么写 | 打开后 |
|---|---|---|
| 脑图笔记 | 一篇 `.md` 笔记，frontmatter 里写 `mindmap: true` | 默认用脑图视图打开，随时能切回 Markdown |
| 笔记里的脑图 | 普通笔记里一个名为 `mindmap` 的代码块（写 `gogoga-mindmap` 也一样），里面是同样的 Markdown | 阅读模式和实时预览里画成脑图，可以直接编辑 |
| 引用已有的脑图 | 像嵌入笔记一样写 `![[产品发布计划]]` | 只读预览，原笔记改了预览跟着变 |

代码块的开头也可以有自己的 frontmatter（`---` 包起来），键和脑图笔记一样，不用写 `mindmap: true`。

嵌入时可以只显示一个分支、指定缩放或尺寸：`![[产品发布计划#时间线]]`、`![[产品发布计划#^abc123]]`、`![[产品发布计划|80%]]`；放在节点里时 `![[产品发布计划|480x300]]` 是预览框的宽高。这些是 Obsidian 的链接写法，不改被引用的笔记。

## 哪些行是节点

```markdown
# 中心主题

## 主主题
### 子主题
- 更深一层
	- 再深一层
```

- **中心主题**是唯一的一级标题 `#`。没有一级标题时用文件名；打开设置「用文件名作中心主题」后始终用文件名，一级标题变成第一级分支。
- **`##` 到 `######`** 依次是下面各层。层级不要跳。
- **列表项**（`-`、`*`、`+` 或 `1.`）接在标题下面，是更深的层级；列表缩进一层就深一层。插件写的时候用 Tab 缩进，读的时候空格缩进也认。
- **有序列表**（`1.` `2.` `3.`）表示这些子节点带编号，脑图上显示数字。子节点是标题时没法写成有序列表，编号改用标记 `num`（见下）。
- 标题最多到 H6，再往下自动改用列表。在脑图里新建节点时，第几级开始用列表由设置决定，默认第四级。这个只影响新写的节点，读的时候标题和列表怎么混都行。
- 两个设置会改变读法，但都不改文件：「只把标题当节点」打开后，脑图笔记里只有标题是节点，标题下面的列表和段落都算它的备注（代码块里的脑图不受影响）；「用文件名作中心主题」见上。
- 每个节点可以有一个 Obsidian 块 id，写在行尾：`- 发布日期 ^abc123`。插件会保留它，`[[笔记#^abc123]]` 这种链接不会断。

## 备注

节点下面不是节点的内容，都算这个节点的**备注**，脑图上显示成一个 ≡ 图标，点开看。

```markdown
## 风险

支付渠道审核最长要三周。

- 服务器容量
	压测排在第二周。
```

- 标题下面的段落、代码块、图片、引用，是这个标题的备注。
- 列表项的备注要缩进到它子节点那一层。
- **备注里有列表或标题时**，要包在 `> [!note]` 里，每行前面加 `> `，否则那些行会变成节点。最后一行 `>` 后面留一个空行，不然 Obsidian 的实时预览会把下面的列表项吸进这个引用块。

```markdown
- 服务器容量
	> [!note]
	> - 第二周压测
	> - 自动扩容兜底

- 下一项
```

- 设置「列表项下的备注写成引用块」打开后，插件写列表项的备注时每行前加 `>`，读的时候去掉一层 `>`。两种写法插件都能读。
- 夹在两个列表中间、或者写在列表后面的段落，不归哪个节点，脑图上不显示，但插件写回时会留在原来的位置。

## Frontmatter

| 键 | 值 | 说明 |
|---|---|---|
| `mindmap` | `true` | 这篇笔记是脑图。代码块里不用写 |
| `mindmap-structure` | `logic-right`（默认）、`mindmap`、`org-down`、`tree-right`、`timeline-h`、`timeline-h-alt`、`timeline-v-right`、`timeline-v-left`、`timeline-v-alt`、`fishbone-right`、`fishbone-left` | 整张图的结构：向右逻辑图、左右分布、组织结构图、树形图、五种时间轴、两种鱼骨图 |
| `mindmap-theme` | `snow`（默认）、`rainbow`、`business`、`warm`、`mono`、`line`、`forest`，或自定义主题的 id（在工具栏切换时由插件写入） | 主题。自定义主题存在设置里，换一台没有这个主题的设备时按默认主题显示 |
| `mindmap-edge` | `curve`、`elbow`、`straight` | 连线形状；不写就跟着主题 |
| `mindmap-edge-dash` | `true`、`false` | 虚线 / 实线；不写就跟着主题 |
| `mindmap-edge-corner` | `sharp`、`round` | 折线的拐角；不写就跟着主题 |
| `mindmap-height` | 像素数，如 `300` | 只对代码块有用：固定这一块的高度 |
| `mindmap-review` | 一串 id（插件生成），手写 `true` 也行 | 整张图加入了间隔复习，id 是复习进度的牌组 |
| `icon` | 如 `lucide:mindmap-tree` | 不是脑图的设置：插件按设置写这个属性，让 Notebook Navigator、Iconize 等在文件列表里显示图标。设置里留空就不写 |

除了 `mindmap: true`，其余都可以不写，不写就用默认或跟着主题。插件只改这些键，frontmatter 里别的属性原样保留。

**Enhancing Mindmap 的文件**：frontmatter 里有 `mindmap-plugin: basic` 的笔记也当脑图打开（Enhancing Mindmap 插件启用着时不自动打开，由它来开；想用这边看，用文件菜单里的「以思维导图打开」）。这种文件里，节点行尾的 `^id`（小写字母、数字和 `-`）表示折叠，和 Enhancing Mindmap 的读法一样；在这边折叠、展开也写成行尾 `^id`，不写 `%%fold%%`，也不加 `mindmap: true`，两个插件来回打开结果一致。

## 标记 `%%…%%`

节点的样式和关系写在 Obsidian 的注释里，阅读模式看不见。**一个节点只有一个注释**，里面的几个标记用空格隔开：`%%blue fold w=240%%`。

- **标题**的标记单独写在标题下面一行。这样标题文字是干净的，`[[笔记#标题]]` 的链接不会断。中间隔了空行也认。早期版本写在标题行末尾，照样能读。
- **列表项**的标记写在行末：`- 事项 %%red%%`。
- 一个注释里只要有一个词不在下表里，整段就是普通注释，插件不读也不改。所以拼写要和下表完全一样。
- 标记里的文字（外框标题、概要、标注）不能有英文双引号 `"` 和 `%%`。

### 样式

| 标记 | 意思 |
|---|---|
| `red` `orange` `yellow` `green` `teal` `blue` `purple` `pink` `gray` | 节点颜色，跟着主题和暗色模式变 |
| `a3e5a2`（6 位或 3 位十六进制，不带 `#`） | 固定色值。不带 `#` 是因为 Obsidian 会把注释里的 `#a3e5a2` 当成标签；读的时候带 `#` 也认 |
| `fold` | 折叠，子节点先收起来 |
| `w=240` | 固定宽度（像素，60–4000），文字自动换行 |
| `num` | 给子节点编号。子节点是列表时直接写成有序列表就行，不用这个 |
| `hide` | 留在笔记里，脑图上不显示 |
| `table` | 节点里显示表格（见[节点里的表格](#节点里的表格)） |

### 结构和位置

| 标记 | 意思 |
|---|---|
| `left` / `right` | 左右分布的图里，这个主主题固定在左边 / 右边 |
| `layout=org-down` | 这个分支单独用一种结构。可选 `logic-right`、`org-down`、`tree-right`、`timeline-h`、`timeline-h-alt`、`timeline-v-right`、`timeline-v-left`、`timeline-v-alt`、`fishbone` |
| `float x=320 y=-80` | 自由主题：中心主题的子节点，不连线，画在相对中心主题偏移这么多像素的位置 |

### 外框、概要、标注

| 标记 | 意思 |
|---|---|
| `box` | 虚线框住这个节点和它的整个分支 |
| `box=3` | 连同后面两个兄弟节点一起框 |
| `box "第一阶段"` | 带标题的外框，可以和 `=3` 一起用：`box=3 "第一阶段"` |
| `summary "每周一同步"` | 在这个分支外侧画一个大括号，后面是概要文字 |
| `summary=2 "文字"` | 概要连同后面一个兄弟一起括。要概括几个兄弟，就写在第一个上 |
| `sw=240` | 跟在 `summary` 后面：概要文字的宽度 |
| `summary-topic=2` | 带子主题的概要：写在被括住的那几项**后面紧跟的一项**上，这一项变成概要（画在括号外），它的子节点挂在它下面。数字是它括住前面几个兄弟 |
| `callout "文字"` | 节点旁边一直显示的小气泡。换行写 `<br>`，彩色字用 `<span style='color:#e03e3e'>文字</span>`（**单引号**） |
| `cc=yellow` | 跟在 `callout` 后面：气泡的填充色，颜色名或不带 `#` 的色值 |

### 关联线

| 标记 | 意思 |
|---|---|
| `id=r1` | 给这个节点起个名字，让关联线能指向它。字母、数字、`-`、`_`，最长 32 个字符；一个节点一个 |
| `rel=r1` / `rel=r1 "依赖"` | 从这个节点画一条虚线箭头到 `id=r1` 的节点，可以带文字。一个节点可以有好几条 |
| `c=40,-60` | 跟在 `rel=` 后面：手动拖过的弯度（一个控制点，相对两端） |
| `c1=…,… c2=…,…` | 跟在 `rel=` 后面：拖过两个控制点手柄（分别相对起点、终点节点的中心） |
| `line=curve` / `straight` / `elbow` | 跟在 `rel=` 后面：这条线的形状 |

`c=`、`c1=`、`c2=` 是插件在你拖动后写的，手写时不用加。

### 间隔复习

| 标记 | 意思 |
|---|---|
| `review` | 只把这个分支加入复习（整张图加入写在 frontmatter 的 `mindmap-review`） |
| `rv=k3j9x2` | 一道复习题的 id，插件生成。改字、挪位置，复习进度都跟着它走；删掉它这道题就从头学 |

## 节点里的表格

带 `table` 标记的节点，把它备注里的第一张 Markdown 表格画在节点框里。表格是标准的 GFM 表格；列表项下的表格要缩进到子节点那一层，和节点之间空一行。只有表格的节点可以不写文字：`- %%table%%`。

```markdown
- 价格 %%table%%

	| 套餐 | 价格 |
	| --- | ---: |
	| 基础版 | 10 |
	| 专业版 | 30 |
	<!-- gogoga-table: {"w":[120,null]} -->
```

表格下面紧跟的那一行 `<!-- gogoga-table: {...} -->` 是 [gogoga Table](https://github.com/JackWeiGogoga/gogoga-table) 的格式，存列宽、颜色、合并单元格这些 GFM 表格写不下的东西。它是 HTML 注释，别的地方看不见；手写时不用加，删了只是丢掉这些样式，表格内容还在。

## 节点文字

节点文字里能用 Obsidian 的行内写法：

- `**粗体**`、`*斜体*`、`~~删除线~~`、`<u>下划线</u>`、`==高亮==`
- `[[笔记]]` 链接、`[文字](https://…)`、`#标签`、`$E=mc^2$` 公式
- `![[图片.png|160]]` 图片（数字是宽度），`![[视频.mp4|400]]`、`![[音频.mp3]]` 播放器
- 彩色文字 `<span style="color:#e03e3e">文字</span>`，彩色高亮 `<mark style="background:#ffd43b99">文字</mark>`，也认 Obsidian 的 `==🔴文字==`（🔴🟠🟡🟢🔵🟣 或 🟥🟧🟨🟩🟦🟪）
- 节点里换行写 `<br>`；开头结尾的空格写 `&nbsp;`（Markdown 会吃掉行首行尾的空格）

几种写在文字开头的东西，插件会特别显示，但它们就是普通字符：

- **任务框**：`[ ]` / `[x]` 写在最前面，显示成勾选框。`- [ ] 事项` 在 Obsidian 里也是任务。
- **图标标记**：开头的 emoji（✅ ⏳ ❗ 1️⃣ 等，或设置里加的自定义符号）显示成节点上的图标。任务框和图标一起用时，任务框写在最前：`[ ] ⭐ 事项`。
- **答案标记**：默认 🙈，可以在设置里换成别的 emoji 或 2～3 个英文符号（比如 `::`，后面要空一格）。带它的节点在背诵模式里先遮住。换了标记以后，已经写了 🙈 的节点照样有效。

## 插件改文件时动哪些东西

- **只改你改动的那几行。** 在脑图里编辑一个节点，文件里只有那一行（和它的标记）变；空行、缩进、列表符号、行尾空格、换行符、你写的普通注释都逐字节保持原样。
- **改名联动。** 中心主题是一级标题、而且和文件名一样时，在脑图里改中心主题会给笔记改名，别的笔记里的链接由 Obsidian 一起更新。两者本来不一样就不联动；设置里可以关掉。
- **万一合并不出完全一致的结果**，会退回按插件的格式整篇写出：结构和内容不变，排版（空行、缩进）按插件的习惯来。这种情况很少。
- **诊断（电脑端）。** 一次保存让笔记变空、少了三成以上、或者出现拼坏的特征时，插件会提示你，并把变化前后的全文存一份在库外（Obsidian 的应用数据目录下的 `gogoga-diagnostics/`），只在本机，不上传、不进同步。

## 不在笔记里的数据

下面这些不写进笔记。删掉它们不影响脑图的内容和样式，只是丢掉对应的状态。

| 数据 | 存在哪 | 丢了会怎样 |
|---|---|---|
| 插件设置 | 插件文件夹的 `data.json` | 回到默认设置 |
| 锁定、备注展开、隐藏标注这类视图状态 | 插件文件夹的 `state.json` | 这些开关回到默认 |
| 视口（平移、缩放、选中的节点） | 本机，按库存在浏览器存储里，不同步 | 打开时重新居中 |
| 间隔复习的排期 | 插件文件夹的 `review/`，每个牌组一个 `.json` | 复习进度从头来；题目还在笔记里 |

插件文件夹是 `<库>/.obsidian/plugins/gogoga-mindmap/`（配置文件夹改过名就是改后的名字）。

## 不装插件时看到什么

- **Obsidian 阅读模式**：一篇有标题和列表的笔记，标记都看不见；代码块里的脑图显示成普通代码。
- **GitHub、Typora 和别的 Markdown 编辑器**：同样是一份大纲。`%%…%%` 不是标准 Markdown，有的编辑器会把它当普通文字显示出来。
- **XMind**：XMind 导出的 Markdown 就是这套标题层级，可以直接打开；反过来这样的笔记也能导入 XMind（颜色、外框这些标记不会带过去）。脑图里也能直接打开 `.xmind` 文件，那是 XMind 自己的格式，不在这一页的范围里。

## 完整示例

````markdown
---
mindmap: true
mindmap-structure: mindmap
mindmap-theme: rainbow
---

# 产品发布

第三季度的发布计划。

## 目标
%%blue%%

- 首月一万注册
- 两家媒体报道

## 时间线
%%green callout "日期待定"%%

- 内测 %%box "第一阶段"%%
	- 邀请 200 位用户
	- 收集反馈
- 正式发布
	- 博客文章
	- 邮件通讯

## 风险
%%red fold id=risk%%

- ❗ 支付渠道审核
	审核最长要三周。
- 服务器容量
	> [!note]
	> - 第二周压测
	> - 自动扩容兜底

## 负责人
%%summary "每周一同步" rel=risk "盯风险"%%

- 小李：产品
- 小王：研发

## 下一步

1. 签合同
2. 招设计师
3. 订场地
````
